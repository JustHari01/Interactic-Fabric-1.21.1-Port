# Interactic (UNOFFICIAL Fabric Port)

An unofficial Minecraft 1.21.1 Fabric port of [Interactic by glisco](https://modrinth.com/mod/interactic). This community port is not affiliated with or endorsed by the original author.

## Features

This port carries the upstream Interactic features:

- **Fancy item rendering:** dropped items spin while falling, lie flat on the ground, and render compactly in stacks.
- **Enhanced pickup and tooltips:** pick up nearby dropped items with right-click and see an item's tooltip below the crosshair.
- **Item Filter:** configure a whitelist or blacklist to control automatic pickup; the mod can also require manual pickup globally.
- **Item throwing:** hold the drop key to charge and throw an item; configurable projectile behavior lets eligible items deal damage.
- **Client-only mode:** use the rendering and tooltip features while server-side features stay disabled.

Feature toggles are controlled by the mod configuration. This release updates the Fabric build to Minecraft 1.21.1 while retaining the upstream implementation and assets.

## Compatibility

- Minecraft 1.21.1
- Fabric Loader 0.16.14 or newer
- Fabric API
- owo-lib 0.12.15.4+1.21 (required)
- Mod Menu 11.0.5 (optional configuration screen)
